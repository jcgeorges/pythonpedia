Pythonpédia

Documentation de l'API REST de l'encyclopédie distribuée consacrée au langage Python.

Présentation du projet

Pythonpédia est une encyclopédie collaborative contenant des références vers des ressources disponibles sur Internet concernant Python.

Les données sont organisées en topics, items et URL. Elles sont réparties sur plusieurs serveurs qui peuvent échanger leurs références.

Cette API permet de consulter les références disponibles sur ce serveur et de découvrir les autres serveurs connus.

Structure des données

Chaque topic représente un thème Python. Chaque item regroupe des URL selon la nature de l'information. 

{
  "fonctions": {
    "definition": [
      "https://docs.python.org/fr/3/tutorial/controlflow.html"
    ],
    "exemple": [
      "https://docs.python.org/fr/3/library/functions.html"
    ]
  }
}

Endpoints disponibles

GET /ws/topics

Renvoie la liste des topics disponibles localement.

Tester cette route 
[
  "fonctions",
  "POO",
  "exceptions"
]

GET /ws/topic/<topic>

Renvoie les items et les URL correspondant au topic demandé.

Exemple : consulter le topic fonctions 
{
  "definition": [
    "https://docs.python.org/fr/3/tutorial/controlflow.html"
  ],
  "exemple": [
    "https://docs.python.org/fr/3/library/functions.html"
  ]
}

Si le topic n'existe pas, l'API renvoie une erreur HTTP 404.

GET /ws/annuaire

Renvoie les adresses des serveurs connus par ce serveur Pythonpédia.

Consulter l'annuaire 
[
  "http://172.20.45.162:5000",
  "http://172.20.45.175:5000"
]

Interroger l'API

Les endpoints utilisent la méthode HTTP GET et retournent des données JSON.

Depuis un terminal, remplacez l'adresse ci-dessous par celle du serveur à consulter : 

curl http://ADRESSE_DU_SERVEUR:5000/ws/topics

L'API peut également être interrogée depuis une application Python avec la bibliothèque Requests. 

import requests

url = "http://ADRESSE_DU_SERVEUR:5000/ws/topics"

reponse = requests.get(url, timeout=5)
reponse.raise_for_status()

print(reponse.json())
